# GEO — география для гимназии

Учебная платформа по трём предоставленным программам: «Maa kui süsteem», «Rahvastik ja majandus», «Loodusvarad ja nende kasutamine».

## Содержание

- 42 авторских урока по 14 тематическим блокам, 126 вопросов в банке (содержание и определения).
- 84 русско-эстонских понятия, карточки с повторением сложных слов.
- Интерактивный атлас, тренировка стран и столиц, пояснения особых политических случаев.
- 5 лабораторий: климатограмма, демография, энергобаланс, водный баланс, тектоника.
- 9 исследовательских работ с заметками и экспортом.
- Локальный прогресс, разбор ошибок, достижения, экспорт/импорт JSON.
- Адаптивная версия, SVG-логотип, PNG-превью 1200×630 и Open Graph/Twitter metadata.

## Запуск

Node.js 20+; внешние зависимости не нужны.

```sh
npm run dev
npm test
npm run build
```

Локальный адрес: http://127.0.0.1:4173. Сборка — `dist/`. Настройки Vercel в `vercel.json`.

## Файлы и расширение

`content.js` содержит курсы, уроки, термины и исследования; `countries.js` — страновые карточки. `core.js` — расчёты моделей и валидация прогресса. `app.js` — интерфейс и маршруты. `style.css` — адаптивное оформление.

Программа содержит по 35 часов на курс. В третьем файле суммы тематических часов дают 31; четыре часа для повторения и исследования предложены платформой отдельно. Учебные темы GEO не равны школьным часам.

Лаборатории используют синтетические данные и обозначенные упрощения, а не текущую статистику или прогноз. Отметка «урок изучен» — самооценка прохождения. Открытые исследования не оцениваются автоматически. Входа, серверной базы пользователей и межустройственной синхронизации нет; прогресс и заметки хранятся в localStorage, резервное копирование — экспорт JSON.

Источники и ограничения доступны в разделе «О программе». Карта: world.geo.json / Natural Earth, обобщённая учебная основа; малые страны представлены точками. Источники научной проверки: USGS, IPCC AR6 и HELCOM. Шрифты Manrope и Unbounded загружаются с Google Fonts с системными запасными шрифтами.

При изменении домена обновите canonical, og:url, og:image и twitter:image в `index.html`. Для предпросмотра ссылки социальным сетям нужен публичный доступ к HTML и PNG.

## Проверка

Автотесты проверяют охват каждого блока программы, связи уроков и терминов, данные стран, расчёты, безопасный импорт и экранирование. Браузерная проверка при создании охватила чтение/сохранение урока, полный тест, карточки, атлас, пять лабораторий, заметки, поиск, прогресс и отсутствие горизонтального переполнения на 390 px.
